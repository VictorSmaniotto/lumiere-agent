# Pasta de Dados Brutos (Insumos de Análise)

Esta pasta armazena **dados brutos não editados** de campo.

---

## Regra de Ouro:
> **Dado não é contexto.** O contexto (`contexto/`) é a verdade oficial consolidada. Os arquivos em `dados/` são os sinais brutos do mundo real.

Se um dado desta pasta contrariar uma definição de `contexto/`, isso **não é um erro**, e sim uma **tensão ou achado de pesquisa** que o copiloto de produto deve reportar.

---

## Arquivos Típicos nesta Pasta:
- `entrevistas.md`: Transcrições ou notas de campo de entrevistas com clientes/usuários.
- `chamados-suporte.csv`: Amostra recente de chamados classificados por categoria e severidade.
- `metricas-funil.csv`: Dados brutos de exportação de analytics.
- `notas-reuniao.md`: Notas soltas e transcrições de reuniões de alinhamento com stakeholders.
